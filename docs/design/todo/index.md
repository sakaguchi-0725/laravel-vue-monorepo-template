# Todo ドメイン

## 概要

タスクの登録と参照を扱うドメイン。  
タスクは件名・詳細説明・ステータス・期限日を持ち、全利用者で共有される（所有者の概念を持たない）。  
ステータスは未完了（`pending`）と完了（`done`）の2種類で、作成直後は常に未完了になる。
