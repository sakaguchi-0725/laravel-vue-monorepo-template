# タスク一覧を取得する

## 概要

登録済みのタスクを期限日の昇順で一覧取得する。  
ステータスを指定した場合は、そのステータスのタスクだけに絞り込む。

## アクター

- 利用者
- 管理者

## 事前条件

- なし（タスクの登録有無を問わず実行できる）

## 受け入れ基準

**正常系: 利用者がタスク一覧を取得できること**

- Given: 期限日が「2026-09-30」「2026-09-01」のタスクが登録されている
- When: ステータスを指定せずにタスク一覧を取得する
- Then: 「2026-09-01」「2026-09-30」の順で、各タスクのID・件名・詳細説明・ステータス・期限日を含む一覧が返る

**正常系: 期限日が未設定のタスクが含まれる場合、期限日ありのタスクより後に並ぶこと**

- Given: 期限日が「2026-09-30」のタスクと、期限日が未設定のタスクが登録されている
- When: ステータスを指定せずにタスク一覧を取得する
- Then: 「2026-09-30」のタスク、期限日が未設定のタスクの順で一覧が返る

**正常系: ステータスを指定した場合、そのステータスのタスクだけが返ること**

- Given: 未完了のタスクと完了済みのタスクが登録されている
- When: ステータスに未完了を指定してタスク一覧を取得する
- Then: 未完了のタスクだけを含む一覧が返り、完了済みのタスクは含まれない

**正常系: タスクが1件も存在しない場合、空の一覧が返ること**

- Given: タスクが1件も登録されていない
- When: タスク一覧を取得する
- Then: 空の一覧が返る

**異常系: 未定義のステータスを指定した場合、取得が拒否されること**

- Given: タスクが登録されている
- When: 未完了・完了のいずれにも該当しない値をステータスに指定してタスク一覧を取得する
- Then: 取得が拒否され、指定したステータスが不正である旨が返る

## 備考

- 期限日が同じタスクが複数ある場合は、ID の昇順で並べる。
- 一覧は絞り込み後の全件を返し、ページネーションは行わない。
- 利用者向け・管理者向けの両方に同一のエンドポイントを提供し、振る舞いは同一。上記は利用者を代表として記述しており、管理者が実行しても結果は変わらない。
