# タスクを作成する

## 概要

件名・詳細説明・期限日を指定してタスクを新規登録する。  
作成されたタスクのステータスは常に未完了になる。

## アクター

- 利用者
- 管理者

## 事前条件

- なし（実行に必要な事前状態はない）

## 受け入れ基準

**正常系: 利用者がタスクを作成できること**

- Given: 件名「請求書を送付する」、詳細説明「今月分の請求書をPDFにして送る。」、期限日「2026-09-30」を入力している
- When: タスクの作成を実行する
- Then: 入力した内容のタスクが未完了として登録され、採番されたIDを含む登録内容が返る

**正常系: 詳細説明と期限日を指定しない場合、いずれも未設定のタスクが作成されること**

- Given: 件名「請求書を送付する」だけを入力している
- When: タスクの作成を実行する
- Then: 詳細説明と期限日が未設定のタスクが未完了として登録され、登録内容が返る

**異常系: 期限日に過去の日付を指定した場合、作成が拒否されること**

- Given: 当日が「2026-08-21」で、期限日に「2026-08-20」を入力している
- When: タスクの作成を実行する
- Then: 作成が拒否され、期限日に過去の日付は指定できない旨が返る。タスクは登録されない

## 備考

- 期限日は当日以降のみ指定できる（過去日のタスクは期限として機能しないため）。当日の判定は Asia/Tokyo を基準とする。
- ステータスは作成時に指定できない（作成と完了操作を分離するため）。完了への変更は本ドメインのスコープ外。
- 利用者向け・管理者向けの両方に同一のエンドポイントを提供し、振る舞いは同一。上記は利用者を代表として記述しており、管理者が実行しても結果は変わらない。
